**Taxonomy Standard:**
- `VERIFIED WORKING`: Confirmed operational via code execution, live sensor telemetry trace, or runtime build artifact.
- `IMPLEMENTED, NOT RUNTIME-VERIFIED`: Full code implementation present, but physical end-to-end hardware loopback was not executed in this environment.

- `MOCKED / SIMULATED`: Operates via synthetic data generator or developer sandbox.
- `UI ONLY`: Visual Composable exists without backing ViewModel/Repository functionality.
- `NOT FOUND`: No code or configuration exists in the active workspace.
- `BLOCKED`: Verification prevented by missing hardware or physical testbench.
